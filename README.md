# 電工ノート — 第二種電気工事士の一問一答

第二種電気工事士の筆記試験で問われる知識を、一問一答で確かめるスマートフォン向けWebアプリです。

## 機能

- 8分野（電気理論、配電理論、機器と材料、工具、施工方法、検査方法、法令、配線図の記号）、全92問
- 1回10問の一問一答。解答を表示したあと、正解か不正解かを自分で判定する
- 不正解と判定した問題の復習出題と、直近50回の学習履歴
- 問題一覧（分野とキーワードで絞り込み）
- ログイン不要・ブラウザ内保存・JSONのダウンロード／インポート
- スマートフォン向け下部ナビゲーション
- ホーム画面に追加してアプリとして開ける（PWA）。一度開いたあとは、通信できない場所でも使える

## 構成

HTML・CSS・JavaScriptのみの静的サイトです。外部API・データベース・ビルドは不要です。

- `docs/index.html`: 画面の入口
- `docs/app.js`: UI・一問一答・記録
- `docs/data.js`: 分野と問題
- `docs/backup.js`: バックアップの形式検証
- `docs/style.css`: レスポンシブデザイン
- `docs/manifest.webmanifest`: ホーム画面に追加したときの名前・アイコン・表示方法
- `docs/sw.js`: オフライン用にファイルを端末へ保存する Service Worker
- `docs/icons/`: アプリのアイコン（192px、512px、iPhone用180px）
- `tests/backup.test.cjs`: バックアップと問題一覧のテスト
- `tests/pwa.test.cjs`: manifest・アイコン・オフライン保存のテスト

## ホーム画面への追加

公開したURLを開き、次の手順で追加します。Service Worker は `https` か `localhost` でしか動かないため、GitHub Pages で公開してから試してください。

- Android（Chrome）: メニュー（︙）→「ホーム画面に追加」または「アプリをインストール」
- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」

Service Worker はオンラインのとき毎回サーバーからファイルを取り直し、通信できないときだけ保存したファイルを使います。`docs/` に新しいファイルを足したときは、`docs/sw.js` の `FILES` にも追加してください。

## ローカル実行

```sh
python3 -m http.server 8000 --directory docs
```

テストはNode.jsの標準機能だけで実行できます。

```sh
node --test tests/*.test.cjs
```

## GitHub Pages

リポジトリの **Settings → Pages** で Source に **Deploy from a branch**、Branch に **main**、Folder に **/docs** を指定します。

## 学習記録

記録は利用中のブラウザの `localStorage`（キー `denko-study-v1`）に保存されます。サーバーへの送信や自動同期は行いません。

公開URLが変わる場合は、旧サイトの「記録」でJSONをダウンロードし、新サイトの「記録」でインポートしてください。インポートは現在の記録を置き換えます。

## 問題の内容について

問題と解説は、試験範囲の代表的な知識を要約したものです。法令や技術基準は改正されることがあるため、一般財団法人電気技術者試験センターが公表している試験問題と、最新年度の参考書で確かめてください。
